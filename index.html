⚙ API Settings (required)

Get a free key at openrouter.ai/keys (no credit card required). This app uses the free openai/gpt-oss-120b:free model — $0 per call, but limited to roughly 20 requests/min and 50/day (1,000/day if you ever add $10 credit to your account). Free endpoints can occasionally be unavailable or rate-limited by the underlying provider — if you see a "No endpoints found" or 429 error, check openrouter.ai/models for a currently active free model and swap the MODEL constant in the code. Key is stored only in your browser's localStorage. ⚠ Client-side keys are visible to anyone inspecting network traffic — fine for personal testing, not for public deployment.
